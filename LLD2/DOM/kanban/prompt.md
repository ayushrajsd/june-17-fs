Create the HTML and CSS for the initial UI of a simple Kanban Board application.

The page should have a clean, modern layout and include the following sections:

* A toolbar at the top that remains visible while scrolling.
* Four clickable priority indicators that represent different task priorities.
* An "Add Task" button that will later be used to open a task creation modal.
* A "Show All" button that will later reset any active filters.
* An empty area where task cards will eventually be displayed.
* A modal (hidden by default) containing a textarea where users can type a new task.

The design does not need to match any specific colour scheme. Feel free to choose your own colours, spacing, typography, border radius, and overall styling.

The layout should be responsive and use modern CSS techniques such as Flexbox or Grid where appropriate.

At this stage, do not implement any JavaScript functionality. Only create the HTML structure and CSS styling. However, keep the HTML well structured so that JavaScript can later:

* Detect which priority indicator is clicked.
* Open and close the modal.
* Read the textarea input.
* Add task cards into the task area.
* Filter tasks based on priority.
* Reset filters using the Show All button.

Use meaningful and semantic HTML wherever possible, and organise the CSS so it is easy to extend in later steps.
